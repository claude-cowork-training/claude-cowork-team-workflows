# Glossary — sample team context file

*(Metamorfeus example. List the terms a smart new hire wouldn't know on day one — that's exactly what Cowork doesn't know either.)*

- **QBR** — quarterly business review (client-facing, deck + one-pager)
- **Digest** — the weekly client status summary (Friday, one page)
- **Pilot** — fixed-fee first engagement; success criteria written before kickoff
- **The board numbers** — revenue, utilization %, pipeline value (always those three, in that order)
- **De-identified extract** — client data with all personal information removed before it reaches us; the only form we ever touch
