# Writing style — sample team context file

*(Metamorfeus example — replace with your team's actual rules. Even five rules make every Cowork output noticeably more consistent.)*

- Plain English, short sentences. Banned words: "leverage", "synergy", "utilize".
- Every number gets a source or an "estimate" label.
- Client-facing docs: one page unless asked otherwise.
- Dates: `2026-05-12` in filenames, "May 12, 2026" in prose.
- Status colors mean something: GREEN = on track, YELLOW = at risk with a named recovery action, RED = off track and escalated.
