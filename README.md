Copied together, teams using all workflows in one category typically replace **8–15 hours of manual work per week** (estimates based on the manual processes each workflow replaces — see each file for how the figure was derived). Every workflow here has been run at least once in Claude Cowork against realistic synthetic business data before publication.

## How to use (3 steps)

1. **Pick one workflow** that matches a task your team already does every week or month. Start with a ●○○ — the single-difficulty ones need no connectors and no special setup.
2. **Do the one-time setup** in that workflow's file (usually: create a folder, drop in 2–3 context files — we include [samples](templates/context-file-examples/)).
3. **Paste the prompt into Claude Cowork** with the folder open. Review the output, adjust the prompt where your team's reality differs, and save your version.

All examples reference a fictional company — **Metamorfeus**, a 24-person AI consultancy — the same synthetic dataset used in our [free interactive Cowork course](https://github.com/claude-cowork-training/cowork-course). If you want practice data before running these on real files, download the course repo and point the workflows at its `scenarios/` folders.
